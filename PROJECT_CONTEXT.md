# Marlex — общий контекст проекта

## Проект и определяющее правило
Marlex — десктопное (Electron, macOS/Windows) и web/PWA-приложение для экспертов и фаундеров: генерирует смысловые карусели для соцсетей через локальный AI (Claude Code/ChatGPT CLI/Gemini CLI/Ollama) или BYOK-режим, включает встроенную студию дизайна и экспортирует контент в PNG/PDF/Telegram/LinkedIn/Threads/Instagram. Новая работа следует целевому состоянию из этого контекста; существующие расхождения — явный техдолг в [[legacy_warning]] и [[migration_backlog]], не повод переписывать всё по пути.

## Рабочие правила
- Изменения — точечные; несвязанный техдолг фиксируется в [[legacy_warning]], а не чинится попутно.
- Новая технология или архитектурное решение не вводится без записи в [[decisions]].
- При изменении зависимости, контракта, интерфейса, границы безопасности или политики верификации — обновляется соответствующий контекст.

## Координация Claude/Codex
- Репозиторий и состояние Git — общая истина; история чата — локальна для конкретного хоста.
- Независимые изменения — в отдельных worktree; пути захватываются заранее.
- Перед записью — перечитать файл; при пересечении — остановиться. В передаче работы — изменённые пути, проверки, что осталось.

## Definition of Done
- [ ] верификация — по [[testing]], включая нужные adversarial-проверки
- [ ] edge cases и границы безопасности — по [[edge_cases]] и [[security]]
- [ ] размещение — по [[architecture]]
- [ ] новая политика/зависимости — с ADR в [[decisions]]
- [ ] затронутый контекст обновлён или долг зафиксирован
