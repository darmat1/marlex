# edge-cases.md — нетипичные сценарии

## Невалидные, пустые, отсутствующие и граничные значения
- `generateContentPackage`: невалидный/усечённый JSON от AI-модели — сегодня обрабатывается через `buildDynamicFallback` с шаблонным контентом на основе ключевых слов; при регрессии этого пути нет проверки, что fallback-контент вообще релевантен теме пользователя (см. [[testing]]).
- `renderSlideToCanvas`: отсутствующее фоновое изображение, 0 слайдов, аномально длинный текст с переносом — не покрыто тестами сегодня.
- `compareSemver`: версии с pre-release-суффиксом (`0.1.4-beta`) и разным числом сегментов — сегодняшняя реализация не обрабатывает суффиксы явно (parseInt отбрасывает нечисловой хвост).

## Ошибки, частичные сбои и восстановление
- `api/index.ts` — необработанные ошибки сегодня отдают `err.message`/`err.stack` клиенту напрямую; целевое состояние — нейтральный ответ клиенту, полная информация только в серверный лог (см. [[decisions#ADR-010]]).
- AI-провайдер недоступен/таймаут — обрабатывается через тот же fallback-путь, что и невалидный JSON.

## Отмена, повтор, дублирование, порядок, конкурентность
- `POST /api/projects` — повторный вызов с тем же `id` сегодня падает на конфликте первичного ключа вместо обновления записи (не идемпотентно) — целевое состояние — upsert (см. [[data_model]]).

## Ограничения ресурсов и окружения
- Desktop-автообновление сравнивает версии через `compareSemver` при каждом запуске — ошибка в сравнении молча ломает баннер обновления для одной архитектуры (arm64/x64), если логика выбора установщика (`dmgAsset`) выберет не тот файл.
- Локальные CLI-агенты (Claude Code/ChatGPT/Gemini/Ollama) могут отсутствовать на машине пользователя — обнаружение в `electron/main.ts` должно деградировать к BYOK-режиму, а не падать.

## Совместимость и эволюция
- Схема Postgres не версионируется миграциями сегодня (см. [[data_model]]) — при следующем изменении схемы это станет источником рассинхронизации между окружениями.

## Разрешения и сбои границ доверия
- `/api/projects` без сессии/ownership-проверки — сегодня возвращает данные всех пользователей и пишет без `userId` (см. [[security]], [[decisions#ADR-003]]). Не эксплуатируется публично только потому, что маршрут не задеплоен — это условие, а не защита.
- CORS reflect-origin + credentials — любой сторонний origin сегодня технически может делать credentialed-запросы к API (см. [[security]]).

## Интерфейс и нетипичное пользовательское взаимодействие
- Списки одиночного выбора (CLI-агент, слайды, фото) и модальные окна — недоступны с клавиатуры/для ассистивных технологий сегодня (см. [[ui_kit]]); целевое состояние — [[decisions#ADR-008]].

## Персистентность и внешний ввод-вывод
- BYOK-ключи в localStorage переживают перезапуск приложения в открытом виде — целевое состояние см. [[security]].
- Кнопка «Сбросить кэш» в error boundary (`src/main.tsx`) удаляла ключ localStorage `'marlex-storage'`, хотя реальный ключ zustand `persist` в `src/lib/store/useMarlexStore.ts` — `'marlex-content-storage-v5'` — кнопка молча не делала ничего. Найдено при верификации этого контекста (не входит в исходные 41 находку аудита), исправлено 2026-08-23.
